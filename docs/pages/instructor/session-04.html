Teaching notes by part

Why this session matters. Sessions 1–3 used tidyverse functions that hide how R stores data. This session opens the hood. Vectors and vectorization explain why mutate() works on a whole column at once; base-R subsetting is everywhere in other people’s code, help pages, and Stack Overflow answers, and learners need it to write functions in Session 8; and reshaping is needed for many summaries and plots.

Part 2 — Vectors and types. Point out that c(1, 2, "unknown") is exactly why one “unknown” turned the whole age column into text in Session 1. Show that ages and the other objects appear in the Variables pane, which also shows each vector’s type and length.

Part 3 — Vectorization. Stress that mutate() is just a vectorized calculation on a column — no loop needed. Point out that sum()/mean() of a comparison counts/gives proportions; they will use mean(fever == "yes") * 100 inside summarise() in Session 5.

Part 4 — Subsetting with base R. Rows first, then columns — have learners say it out loud. A common slip is forgetting the comma (df[1:3] picks columns). Spend time on the NA warning box: nrow(linelist[linelist$temp > 40, ]) gives 244, nrow(filter(linelist, temp > 40)) gives 93 — base R adds a row of NAs for each of the 151 missing temperatures. The Part 4 TRY IT (c) repeats this trap on the measles data (225 vs 196, 29 missing ages), so let learners discover it before you explain.

Part 5 — Lists. The one data structure the tidyverse sessions never show, and the one learners hit first in real analyses: every test and model result is a list, and so is every Bioconductor object. Use the box analogy: [[ ]] takes the item out of the box, [ ] gives a smaller box. Show is.list(linelist) — the “aha” that a data frame is a list of columns explains $, [[ ]], and (in Session 8) why map() runs once per column. For t.test(), say explicitly that the statistics come later; the point here is the shape of the result. Expect the “exactly 2 levels” error if someone forgets to filter out “Unknown” — it’s a useful mistake.

Part 6 — Tidy data and pivot_longer(). Point out that “observation” depends on the question: wide symptoms are fine for one symptom at a time, but long format lets one count() handle all five. nrow(symptoms_long) is 32255 = 6451 patients × 5 symptoms. The plot is a preview of Session 6 — don’t explain ggplot yet.

Part 7 — pivot_wider(). Emphasize the rule of thumb: long for R, wide for people. Mention values_fill = 0 (the hospital × outcome table has no empty combinations, so it isn’t needed here).

Wrap-up. Today: vectors and types, c(), class(), vectorized maths and comparisons, sum()/mean() of TRUE/FALSE, [ ], $, [[ ]], lists and str(), test results as lists, tidy data, pivot_longer(), pivot_wider(). Next is Session 5 (Summarizing: count(), group_by() + summarise(), tabyl(), Table 1); Session 8 returns to vectors and subsetting when writing functions and loops.
