Part 2: The grammar of graphics

Every ggplot is built from the same parts, added together with +. The function ggplot() and all the functions in this session that start with geom_, stat_, scale_, or theme_, as well as aes() and labs(), come from the ggplot2 package, part of the tidyverse:

Part Function Question it answers
Data ggplot(data = ...) Which data frame?
Aesthetics aes() Which columns go on x, y, color, fill, …?
Geometry geom_...() What shape: bars, points, boxes, lines?
Labels labs() Title and axis names
Theme theme_...() The overall look

Build it up one piece at a time, and run the code after every + so you can see what each layer adds:

👀 Follow along 2.1 — Build a plot in three steps: 1. ggplot(data = linelist), 2. add aes(x = age_years), 3. add geom_histogram() (the next three code blocks).

# 1. Data only: an empty canvas
ggplot(data = linelist)
# 2. Add aesthetics: the axes appear, but nothing is drawn yet
ggplot(data = linelist, mapping = aes(x = age_years))
# 3. Add a geometry: now we have a plot
ggplot(data = linelist, mapping = aes(x = age_years)) +
  geom_histogram()
Note🔍 What this code does
  • ggplot(data = linelist) says which data frame to use, and draws an empty canvas. ggplot doesn’t know yet what to draw.
  • mapping = aes(x = age_years) says which column goes where: age_years on the x-axis. ggplot now draws the axis, covering ages 0 to 84, but still no shapes.
  • + geom_histogram() adds a layer that draws bars. ggplot counts how many patients fall in each age range and puts that count on the y-axis for you: you don’t have to make a count column.
  • The message “using bins = 30” means ggplot split the ages into 30 bars because you didn’t choose a width. The warning “Removed 96 rows” means 96 patients have no age, so they can’t be drawn.
Important+ not %>%

Layers of a ggplot are joined with +. Using %>% between ggplot layers is the most common beginner error. Like the pipe, + goes at the end of a line, not the start of the next one.

WarningCommon mistakes

  • Putting + at the start of the next line:

    ggplot(data = linelist, mapping = aes(x = age_years))
  + geom_histogram()

    R runs the first line on its own as a complete command (and draws the empty axes). Then it reaches + geom_histogram() with nothing on the left and stops with: Cannot use + with a single argument. Did you accidentally put + on a new line? Move the + to the end of the first line.

Note📖 Good to know
  • The package is called ggplot2, but the function is ggplot(). The “gg” stands for the grammar of graphics: the idea that any plot can be described by its data, which columns go where (aesthetics), and which shapes are drawn (geometries).
  • Plots appear in Positron’s Plots pane. Its arrows take you back to earlier plots, so you can compare versions.
  • Plotting doesn’t change your data. You can experiment as much as you like.

Part 3: Histograms

A histogram shows the distribution of one number: the values are grouped into ranges (“bins”), and each bar’s height is how many values fall in that range.

R warned us above that it picked 30 bins. Choose the bin width yourself:

👀 Follow along 3.1 — Age histogram with binwidth = 5 (then try 1 and 10).

ggplot(data = linelist, mapping = aes(x = age_years)) +
  geom_histogram(binwidth = 5)

Each bar is now 5 years wide. Try binwidth = 1 and binwidth = 10 — what changes?

Note🔍 What this code does
  • binwidth = 5 makes every bar 5 years wide, instead of 30 bars of whatever width fits the data.
  • ggplot centers the bars on 0, 5, 10, and so on. So the tallest bar covers ages 2.5 to 7.5, and holds 1190 patients. To start the bars at 0, 5, 10 instead, add boundary = 0.
  • Narrow bins show more detail but look noisy; wide bins look smooth but hide detail. There’s no single right width, so try a few.

Fixed colors

Inside geom_histogram(), fill is the inside color and color is the outline. A white outline separates the bars.

👀 Follow along 3.2 — Add fill = "#2a78d6" and color = "white".

ggplot(data = linelist, mapping = aes(x = age_years)) +
  geom_histogram(binwidth = 5, fill = "#2a78d6", color = "white")
Note🔍 What this code does
  • fill and color are given inside geom_histogram(), so they apply to every bar. fill colors the inside of the bars, and color the outline.
  • "#2a78d6" is a hex code for a blue: a #, then two characters each for the amount of red, green, and blue.
  • The white outline draws a thin line between neighboring bars, so you can tell them apart.
NoteColors in R

Use a name ("steelblue", "gray50") or a hex code ("#2a78d6"). Run colors() to see all 657 named colors.

Note🔁 The base R way: hist()

Base R has its own plotting functions, and you’ll see them in older code and in help pages. hist() draws a histogram from one column (reading only, you don’t need to type this):

hist(linelist$age_years)
Note🔍 What this code does
  • hist(linelist$age_years) takes one column with $ and draws a histogram right away: no aes(), no layers, no +.
  • R picks the bins itself (here 5 years wide, starting at 0), so the tallest bar is ages 0 to 5, with 1427 patients. It skips the missing ages without a warning.
  • The title and axis label come from the code itself (“linelist$age_years”). You’d change them with arguments such as main = and xlab =.

plot(x, y) makes a scatter plot and boxplot(y ~ group, data = ...) a box plot. Base R plots are quick for a first look, but each kind of plot works a bit differently, and you can’t add layers to them later. That’s why this workshop uses ggplot.

Note📖 Good to know
  • A histogram is for one number, like age: the bars touch because the ranges follow each other. For categories, like hospital or outcome, you use a bar chart instead (Session 7).
  • When ggplot can’t draw some rows, because a value is missing, it drops them and tells you how many in a warning. Read the number: it’s a quick check that it’s the count of missing values you expected.

Part 4: Mapping vs setting

This is the key idea of ggplot:

  • Mapping — inside aes(): a column controls the color. Different values get different colors, and you get a legend.
  • Setting — outside aes(): one fixed color for everything.

👀 Follow along 4.1 — Age histogram with fill = outcome inside aes().

# Mapping: fill depends on the outcome column
ggplot(data = linelist, mapping = aes(x = age_years, fill = outcome)) +
  geom_histogram(binwidth = 5, color = "white")
Tip🧩 Reading a function call

Here is the plot you just made, taken apart:

ggplot(data = linelist, mapping = aes(x = age_years, fill = outcome)) +
  geom_histogram(binwidth = 5, color = "white")
Piece What it is What it does
ggplot(...) the function that starts every plot sets up the canvas
data = linelist the first argument of ggplot() which data frame to draw from
mapping = aes(...) the second argument: the aesthetic mapping links columns to parts of the plot
x = age_years inside aes() age goes on the x-axis
fill = outcome inside aes(), so a mapping the outcome column decides each bar’s color
+ joins layers adds the next layer to the plot
geom_histogram(...) a geometry layer draws the data as a histogram
binwidth = 5 an argument of geom_histogram() each bar covers 5 years
color = "white" outside aes(), so a setting a white outline on every bar

Unlike one function inside another, a ggplot reads from left to right, one layer after the other: “Take linelist, put age on the x-axis and color by outcome, then draw a histogram with 5-year bins and white outlines.”

Note🔍 What this code does
  • fill = outcome is inside aes(), so it’s a mapping: the outcome column decides each bar’s color.
  • ggplot gives each outcome a default color (pink-red for Recover, green for Death, blue for Unknown) and adds a legend. The bars are stacked: each bar’s full height is still every patient of that age, split into the three outcomes.
  • The colors follow the order you set with fct_relevel(). In Session 7 you choose the colors yourself.

👀 Follow along 4.2 — The same with fill = "#2a78d6" in geom_histogram().

# Setting: every bar is blue
ggplot(data = linelist, mapping = aes(x = age_years)) +
  geom_histogram(binwidth = 5, fill = "#2a78d6", color = "white")
Note🔍 What this code does
  • fill = "#2a78d6" now sits inside geom_histogram(), outside aes(). That makes it a setting: one fixed color for every bar, and no legend.
  • Nothing else changed. Where you put fill decides whether a column controls the color or you do.

👀 Follow along 4.3 — What happens with fill = "blue" inside aes()? Open the box below and try it.

Note🤔 Think about it: what happens if you put fill = "blue" inside aes()? Try it! 
ggplot(data = linelist, mapping = aes(x = age_years, fill = "blue")) +
  geom_histogram(binwidth = 5)

The bars are pink-red and the legend says “blue”! ggplot treated “blue” as data — a column whose every value is the word “blue” — and gave it the first default color.

Note🔍 What this code does
  • Inside aes(), ggplot expects a column name. "blue" is text, not a column, so ggplot treats it like a column where every row says “blue”: one group, which gets the first default color.
  • To make the bars blue, move fill = "blue" out of aes() and into geom_histogram().
WarningCommon mistakes
  • aes(fill = "blue") does not make blue bars. To use one fixed color, put fill = "blue" in the geom_...(), outside aes().

Part 5: Scatter plots

A scatter plot shows the relationship between two numbers: one point per row.

👀 Follow along 5.1 — age_years vs wt_kg with geom_point().

ggplot(data = linelist, mapping = aes(x = age_years, y = wt_kg)) +
  geom_point()
Note🔍 What this code does
  • aes(x = age_years, y = wt_kg) maps two columns: age across, weight up.
  • geom_point() draws one point per row, so one point per patient. 6322 patients have both an age and a weight; ggplot warns that it removed the other 129 rows.

With 6,000+ points, many sit on top of each other. Make them smaller and see-through with size and alpha (0 = invisible, 1 = solid):

👀 Follow along 5.2 — Add size = 1 and alpha = 0.3; then map color = gender (the next two code blocks).

ggplot(data = linelist, mapping = aes(x = age_years, y = wt_kg)) +
  geom_point(size = 1, alpha = 0.3)

Map a third variable to color

ggplot(data = linelist, mapping = aes(x = age_years, y = wt_kg, color = gender)) +
  geom_point(size = 1, alpha = 0.4)
Note🔍 What this code does
  • size = 1 makes the points smaller, and alpha = 0.3 makes them 70% see-through. Where many points overlap, the color builds up and looks darker, so you can see where most patients are.
  • These are settings, so they go in geom_point(), outside aes().
  • In the second plot, color = gender is inside aes(): a mapping. Each gender gets its own color and a legend entry. Points use color; bars and boxes use fill for the inside.

Add a trend line

geom_smooth() adds a trend line on top of the points. method = "lm" draws a straight line (linear model); se = FALSE hides the confidence band.

👀 Follow along 5.3 — Add geom_smooth(method = "lm", se = FALSE, color = "#eb6834").

ggplot(data = linelist, mapping = aes(x = age_years, y = wt_kg)) +
  geom_point(size = 1, alpha = 0.3) +
  geom_smooth(method = "lm", se = FALSE, color = "#eb6834")
Note🔍 What this code does
  • geom_smooth() adds a second layer on top of the points. Both layers use the same aes() from ggplot(), so the line uses the same x and y.
  • method = "lm" draws the straight line that fits the points best (a linear model). se = FALSE hides the gray band that shows how uncertain the line is.
  • The line starts at about 34 kg at age 0 and rises about 1.2 kg per year of age. A straight line can’t bend, so it misses how fast children grow.
  • The message “geom_smooth() using formula = ‘y ~ x’” just tells you what the line fits: y (weight) from x (age).

Filter right inside ggplot()

You can pipe data into ggplot(), so you can filter() first without making a new object. Here, only patients with fever (reading only, you don’t need to type this; you’ll use the same idea in TRY IT 5):

linelist %>%
  filter(fever == "yes") %>%
  ggplot(mapping = aes(x = age_years, y = wt_kg)) +
  geom_point(size = 1, alpha = 0.3)
Note🔍 What this code does
  • linelist %>% filter(fever == "yes") keeps the 5077 patients with fever. The pipe then passes them into ggplot() as its data.
  • There’s no data = in ggplot(), because the pipe already supplies the data.
  • After ggplot(), layers are joined with +. The rule: %>% before ggplot(), + after it.
  • linelist itself isn’t changed: the filter only applies to this plot.

Notice the switch: %>% into ggplot(), then + between layers.

Part 6: Box plots

A box plot compares the distribution of a number across groups:

  • The thick line is the median
  • The box holds the middle 50% of values (from the 25th to the 75th percentile — the IQR)
  • The whiskers reach the most extreme values within 1.5 × IQR of the box
  • Points beyond the whiskers are possible outliers

👀 Follow along 6.1 — age_years by gender with geom_boxplot().

ggplot(data = linelist, mapping = aes(x = gender, y = age_years)) +
  geom_boxplot()
Note🔍 What this code does
  • aes(x = gender, y = age_years) puts the groups on the x-axis and the number on the y-axis.
  • geom_boxplot() draws one box per group: female, male, and Unknown. The thick line in the male box (median 17) sits higher than in the female box (median 11).

Clean it up

Remove the “Unknown” group, color the boxes, and drop the legend (the x-axis already names the groups):

👀 Follow along 6.2 — Filter out “Unknown”, add fill = gender, and remove the legend.

linelist %>%
  filter(gender != "Unknown") %>%
  ggplot(mapping = aes(x = gender, y = age_years, fill = gender)) +
  geom_boxplot() +
  theme(legend.position = "none")
Note🔍 What this code does
  • filter(gender != "Unknown") keeps every row where gender is not “Unknown”. != means “not equal”.
  • fill = gender inside aes() colors each box by gender.
  • theme(legend.position = "none") removes the legend. The x-axis already names each box, so a legend would only repeat it.

Add the mean

stat_summary() calculates a statistic for each group and draws it. Here, the mean as a diamond (reading only, you don’t need to type this; you can copy the stat_summary() line in TRY IT 6):

linelist %>%
  filter(gender != "Unknown") %>%
  ggplot(mapping = aes(x = gender, y = age_years, fill = gender)) +
  geom_boxplot() +
  stat_summary(fun = mean, geom = "point", shape = 23, size = 3, fill = "white") +
  theme(legend.position = "none")
Note🔍 What this code does
  • stat_summary() calculates one number for each group and draws it. fun = mean calculates the mean age, and geom = "point" draws it as a point.
  • shape = 23 is a diamond that can be filled, size = 3 makes it bigger, and fill = "white" makes it white so it stands out against the box.
  • The means are 12.7 years (female) and 19.5 (male).
Note🤔 Think about it: why is the mean (diamond) above the median (line)?

The ages are right-skewed: a few older patients pull the mean up. For example, the median age of female cases is 11 but the mean is 12.7.

Note

geom_violin() shows the full shape of each distribution. Try swapping it in for geom_boxplot().

Part 7: Labels and themes

labs()

👀 Follow along 7.1 — Add labs() to the box plot.

linelist %>%
  filter(gender != "Unknown") %>%
  ggplot(mapping = aes(x = gender, y = age_years, fill = gender)) +
  geom_boxplot() +
  labs(
    title    = "Age distribution by gender",
    subtitle = "Cases with known gender",
    x        = "Gender",
    y        = "Age (years)",
    caption  = "Source: workshop outbreak linelist"
  ) +
  theme(legend.position = "none")
Note🔍 What this code does
  • labs() sets the text around the plot: the title, a subtitle, the x and y axis labels, and a caption at the bottom, often used for the data source.
  • Each label is text, so it’s in quotes. Lining up the = signs is optional: it only makes the code easier to read.
  • labs() is one more layer, added with +. The data and the boxes stay the same.

Themes

A theme changes the look of everything that isn’t data: background, grid lines, fonts. Try theme_minimal(), theme_classic(), theme_bw(), and theme_light().

👀 Follow along 7.2 — Try theme_minimal(), theme_classic(), and theme_bw() on the age histogram.

ggplot(data = linelist, mapping = aes(x = age_years)) +
  geom_histogram(binwidth = 5, fill = "#2a78d6", color = "white") +
  labs(
    title = "Age distribution of cases",
    x     = "Age (years)",
    y     = "Number of cases"
  ) +
  theme_minimal(base_size = 14)
Note🔍 What this code does
  • theme_minimal() is a complete theme: it restyles everything that isn’t data. Here it removes the gray background.
  • base_size = 14 sets the size of all the text at once (the default is 11).
  • Swap in theme_classic() or theme_bw() to compare: only the look changes, never the data.

base_size makes all the text bigger — useful for slides.

WarningOrder matters

A complete theme like theme_minimal() resets everything, so put it before theme(legend.position = ...) or your change will be overwritten.

Save a plot as an object

A plot can be saved with <- and built on later:

👀 Follow along 7.3 — Save a plot as age_plot, then add labs() and a theme to it.

age_plot <- ggplot(data = linelist, mapping = aes(x = age_years)) +
  geom_histogram(binwidth = 5, fill = "#2a78d6", color = "white")

age_plot +
  labs(title = "Age distribution of cases", x = "Age (years)", y = "Number of cases") +
  theme_minimal()
Note🔍 What this code does
  • age_plot <- ggplot(...) + geom_histogram(...) saves the plot as an object instead of drawing it. age_plot appears in the Variables pane.
  • age_plot + labs(...) + theme_minimal() adds layers to the saved plot and draws the result. age_plot itself doesn’t change unless you save again with <-.
  • This way you can try different labels and themes without retyping the whole plot.

    title    = "Temperature of measles cases",

    x        = "Temperature (°C)",
    y        = "Number of cases",
    fill     = "Fever",
    caption  = "Source: practice measles linelist"
  ) +
  theme_minimal(base_size = 14)

my_plot

This is one example — any measles plot works. The title is in the subtitle here, as a finding. fill = "Fever" inside labs() renames the legend title, and base_size = 14 makes the text bigger. Saving the plot as my_plot stores it in the Variables pane, and typing its name draws it.

Key points

  • Every ggplot needs data, aesthetics (aes()), and a geometry (geom_...()); layers are joined with +, not %>%.
  • geom_histogram() shows the distribution of one number — choose the binwidth yourself.
  • Mapping (inside aes()) lets a column control color and adds a legend; setting (outside aes()) uses one fixed color.
  • geom_point() shows the relationship between two numbers; alpha and size help with overlapping points, and geom_smooth(method = "lm") adds a trend line.
  • geom_boxplot() compares a number across groups; stat_summary() adds the mean.
  • + goes at the end of a line. A + at the start of a line gives “Cannot use + with a single argument”.
  • labs() adds titles and axis labels, and a complete theme like theme_minimal() changes the overall look (put it before theme(...) changes).
  • You can pipe data into ggplot() to filter() first, and save a plot as an object with <-.
