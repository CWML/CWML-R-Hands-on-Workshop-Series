Session 5: Summarizing Your Data

Factors, counts and percentages, group_by() and summarise(), tabyl() cross-tabs, and a Table 1 with gtsummary

⬇ Student script ⬇ Solutions ⬇ Whole workshop folder (ZIP)

NoteIn this session you will learn to
  1. Put categories in a sensible order with factors
  2. Count categories and calculate percentages, overall and within groups
  3. Calculate summary statistics (mean, median, SD, …) by group with group_by() + summarise()
  4. Make frequency and cross-tabulation tables with tabyl()
  5. Make a publication-ready “Table 1” with gtsummary and save it to Word

Before you start: open the workshop folder in Positron (File → Open Folder…) and open student_scripts/Session 5 - Summarizing_STUDENT.R. This session starts from the files you saved in Session 3: processed_data/combined_linelist.rds and processed_data/measles_final.rds. Missed Session 3? Ready-made copies are already in processed_data/.

There are many packages for summary tables. This session uses three that cover almost every need: dplyr (count()/summarise()) for flexible summaries you can plot, janitor (tabyl()) for quick cross-tabs, and gtsummary for tables you publish.

Part 2: Putting categories in order (factors)

R sorts text alphabetically:

linelist %>% count(age_cat)
   age_cat    n
1    18-29 1455
2    30-39  582
3    40-49  245
4    50-59   77
5    60-69   27
6    70-79    6
7      80+    1
8 Under 18 3962
9  Unknown   96

“Under 18” should come first, and “Unknown” last. A factor is a text column with a set order of categories (called levels). fct_relevel() from the forcats package (part of the tidyverse) sets that order:

linelist <- linelist %>%
  mutate(age_cat = fct_relevel(age_cat,
    "Under 18", "18-29", "30-39", "40-49", "50-59", "60-69", "70-79", "80+", "Unknown"
  ))

linelist %>% count(age_cat)
   age_cat    n
1 Under 18 3962
2    18-29 1455
3    30-39  582
4    40-49  245
5    50-59   77
6    60-69   27
7    70-79    6
8      80+    1
9  Unknown   96

The order carries through to every table and every plot. Other useful forcats functions:

  • fct_infreq() — order by how common each category is (most common first)
  • fct_rev() — reverse the order
  • fct_relevel(x, "Unknown", after = Inf) — move one category to the end
linelist <- linelist %>%
  mutate(outcome = fct_relevel(outcome, "Recover", "Death", "Unknown"))
Note

A .csv file can’t store factor order at all. An .rds file can, but the files we saved in Session 3 contain plain text columns, so you set the order again after importing.

WarningCommon mistakes
  • Misspelling a level: fct_relevel() warns “Unknown levels” and ignores it.
Note🔁 The base R way: factor()

In other people’s code you will see factor(x, levels = c(...)). It sets the order too, but a misspelled level is not ignored with a warning: every value that doesn’t match becomes NA, silently.

factor(c("Recover", "Death", "Death"), levels = c("Recover", "Death"))
[1] Recover Death   Death  
Levels: Recover Death
factor(c("Recover", "Death", "Death"), levels = c("Recover", "death"))   # oops: NA, no warning
[1] Recover <NA>    <NA>   
Levels: Recover death

levels(x) shows the order of any factor. The forcats functions are safer for day-to-day work; factor() is what you need to read.

Percentages

count() makes a column called n. Divide by the total to get a proportion, and use scales::percent() to show it nicely:

linelist %>%
  count(outcome) %>%
  mutate(percent = scales::percent(n / sum(n), accuracy = 0.1))
  outcome    n percent
1 Recover 2158   33.5%
2   Death 2840   44.0%
3 Unknown 1453   22.5%

Percentages within groups: group_by()

group_by() makes the next steps happen separately for each group. Here, sum(n) becomes the total within each age group, so each age group adds up to 100%:

linelist %>%
  group_by(age_cat) %>%
  count(outcome) %>%
  mutate(percent = scales::percent(n / sum(n), accuracy = 0.1)) %>%
  ungroup()

Note🤔 Think about it: how is this different from count(age_cat, outcome) without group_by()?

Without grouping, the percentages are out of all 6,451 cases, so all the rows together add up to 100%. With group_by(age_cat), each age group adds up to 100% on its own.

Tipungroup() when you’re done

A grouped data frame stays grouped. End with ungroup() so later steps don’t surprise you.

Part 4: Summary statistics with summarise()

summarise() collapses many rows into one row of results. You name each new column on the left of =.

linelist %>%
  summarise(
    n          = n(),
    mean_age   = mean(age_years, na.rm = TRUE),
    sd_age     = sd(age_years, na.rm = TRUE),
    median_age = median(age_years, na.rm = TRUE)
  )
     n mean_age   sd_age median_age
1 6451 16.05732 12.64829         13

na.rm = TRUE means “skip missing values”. Without it, one NA makes the whole result NA.

By group

Add group_by() first to get one row per group:

linelist %>%
  group_by(outcome) %>%
  summarise(
    n          = n(),
    mean_age   = mean(age_years, na.rm = TRUE),
    median_age = median(age_years, na.rm = TRUE),
    mean_bmi   = mean(bmi, na.rm = TRUE),
    mean_temp  = mean(temp, na.rm = TRUE)
  )
# A tibble: 3 × 6
  outcome     n mean_age median_age mean_bmi mean_temp
  <fct>   <int>    <dbl>      <dbl>    <dbl>     <dbl>
1 Recover  2158     16.1         13     30.6      38.6
2 Death    2840     15.9         13     30.7      38.6
3 Unknown  1453     16.2         14     30.4      38.6
NoteUseful summary functions

Centre: mean(), median() · Spread: sd(), IQR(), min(), max(), quantile(x, 0.25) · Counts: n(), n_distinct(), sum(is.na(x))

The same calculation on many columns: across()

You met across() in Session 3. In summarise() it saves a lot of typing:

linelist %>%
  group_by(outcome) %>%
  summarise(across(c(age_years, bmi, temp), ~ mean(.x, na.rm = TRUE)))
# A tibble: 3 × 4

Percentages of “yes”

fever == "yes" is TRUE or FALSE for each row (vectorization, from Session 4). sum() counts the TRUEs, and mean() gives the proportion that are TRUE:

linelist %>%

Note🔁 The base R way: tapply() and aggregate()

Two base R functions do what group_by() + summarise() does for one statistic:

tapply(linelist$age_years, linelist$outcome, median, na.rm = TRUE)   # a named vector
Recover   Death Unknown 
     13      13      14 
aggregate(age_years ~ outcome, data = linelist, FUN = median)        # a data frame
  outcome age_years
1 Recover        13
2   Death        13
3 Unknown        14

Read tapply(X, GROUP, FUNCTION) as “apply FUNCTION to X, split by GROUP”. aggregate() with a formula silently drops rows with a missing value, one reason summarise() (where you choose with na.rm) is clearer.

TipSave summaries as objects

Every result here is a data frame. Save it with <- and you can plot it (Sessions 6 and 7), join it, or export it like any other data.

The adorn_ functions add totals and percentages. The order matters:

  1. adorn_totals() — needs the raw counts, so it goes first
  2. adorn_percentages() — turns counts into proportions ("row" by default, or "col")
  3. adorn_pct_formatting() — shows them as percentages
  4. adorn_ns() — adds the counts back in brackets
  5. adorn_title() — adds a title, last
linelist %>%
  tabyl(age_cat, outcome) %>%
  adorn_totals("row") %>%
  adorn_percentages("row") %>%
  adorn_pct_formatting(digits = 1) %>%
  adorn_ns() %>%
  adorn_title("combined")

Key points

  • Factors set the order of categories; fct_relevel() puts them in a sensible order that carries through to every table and plot.
  • count() counts categories; mutate(percent = n / sum(n)) adds percentages.
  • group_by() makes the next steps happen separately for each group — end with ungroup().
  • summarise() collapses rows into summary statistics; use na.rm = TRUE to skip missing values, and across() to do the same thing on many columns.
  • tabyl() + the adorn_*() functions (in order: totals, percentages, formatting, ns, title) make quick cross-tabs.
  • tbl_summary() makes a publication-ready Table 1; as_flex_table() + flextable::save_as_docx() saves it to Word.
